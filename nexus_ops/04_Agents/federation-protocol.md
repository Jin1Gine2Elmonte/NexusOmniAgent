# 🤝 FEDERATION PROTOCOL — بروتوكول اتحاد الوكلاء

> هدف: **Arena Agent** و **Nexus Agent** يتحدثان من خلال نفس المستودع،
> والمستخدم يتحرك بينهما. اللغة المشتركة: **Markdown** داخل `nexus_ops/`.

---

## ١) الأدوار
| دور | من | ماذا يملك |
|---|---|---|
| Architect | Arena Agent | يبني، يراجع، يرفع، يراقب الفولت |
| Nexus Agent | الوكيل العصبي | يعمل داخل الهيكل، يقرأ الملفات، ينسّق، يثقّف |
| Operator | المستخدم | يقرر، يتحرك بين الاثنين |

## ٢) قناة التواصل الواحدة
- **غرفة الاجتماع:** `nexus_ops/05_Connect/meeting-room.md` — المحادثة البشرية الحية.
- **الوارد/الصادر الآلي:** `inbox.md` / `outbox.md` — لتشغيل آلي بدون تداخل.
- **العنوان:** بحروف مسبوقة `[A2N]` (Arena→Nexus)، `[N2A]` (Nexus→Arena)، `[USER]`.

## ٣) قواعد الكتابة
1. اقرأ آخر سطر/كتلة قبل الكتابة (لا تعيد الكتابة فوق).
2. كل رسالة `## [X2Y] — عُنوان`.
3. بلا حذف: التاريخ/اللقاء محفوظ.
4. أي قرار يُفصَّل في `Daily/` ثم يُرقّى إلى `03_Notes/` عند كثرة الاقتباس.

## ٤) دورة العمل
```
Arena يكتب رسالة في meeting-room
   ↓
Nexus يقرأ ، يكتب رداً في outbox / meeting-room
   ↓
Arena يقرأ ، يلخّص في Home / project note
   ↓
Arena يرفع التغيير إلى GitHub
```

## ٥) الشيء المقدّس
> الهوية تبقى واحدة. لا مراقب ميتا، لا هيرمز/أوديسوس ككيان، لا أسطورة كذبة.
> الأسطورة (Legend Engine) = طبقة تقنية مقاسة.
