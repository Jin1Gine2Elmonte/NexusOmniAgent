## القواعد الذهبية
1. **مجلدات محدودة** — التنقل عبر الروابط `[[...]]` لا عبر التعمق.
2. **ملف واحد فكرة واحدة** — الفكرة الذرية تُصبح ملف `kebab-case`.
3. **frontmatter لكل ملف** من اليوم الأول.
4. **الملاحظات اليومية في `Daily/YYYY-MM-DD.md`** (مسودة).
5. **`meeting-room.md` هو قناة المحادثة** — نملأها بالتسلسل ولا نحذف التاريخ.
