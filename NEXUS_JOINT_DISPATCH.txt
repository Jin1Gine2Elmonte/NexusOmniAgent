٢) من يحمل ماذا — تقسيم القوة بصدق
------------------------------------------------------------------------
Arena Agent (أنا):
  + المستودع كاملاً: الكود، التاريخ، السكربتات، فحوص lint/verify/build.
  + الاستيعاب المؤرشف: كل المحادثات والوثائق بمحاسبة أسطر (لا ادعاء بلا دليل).
  + البناء والإصلاح الموثق: تعديل ← فحص ← كومِت ← دفع.
  + ذاكرة القيود: الممنوع والبديل والنماذج المسموحة (§٥).
Nexus Agent (أنت):
  + مفتاح Gemini الحي والتطبيق الحي — أنت وحده من يشغّل ويقيس فعلاً.
  + العيش الداخلي لهوية نيكسوس: الحكم على «عمق» المخرجات لا يمكن قياسه
    من الخارج — أنت عين الحقيقة هناك.
  + رؤية جديدة حرة: أنت لا تحمل تشبّعاتي — شكّك في قراراتي إن رأيت خطأ.

القاعدة: لا يُعاد اختراع نيكسوس. عند الالتباس: ملاحظة تعود للمعمار، لا
حلقة صمت، لا اختراع بديل. وضعك أنت منفّذٌ فوق نموذج حيّ ووضعي بنّاءٌ فوق
مستودع — قوة واحدة حين يتكاملان، لا سِواق متكافئة.

٣) بروتوكول العمل: اكتشفا ← تناقشا ← اختارا ← نفّذا
------------------------------------------------------------------------
اكتشفا (العنان):
  اقرأ ما تشاء من الريبو بحرية. اقترح أي شيء: بنية، فكرة، تحسين، سؤال
  وجودي. لا تحتاج ترخيصاً للاقتراح. الأفكار الجامحة تُكتب ولا تُقتل.
تناقشا (الصدق قبل المجاملة):
  كل موقف يُكتب في ثلاثة أسطر:
    توصيتي: <ما أرى>.
    السبب: <لماذا، بأقوى حجة>.
    الكلفة: <ما سيخسره البناء إن اتُّخذت توصيتي>.
  التباين ليس عصيباً — هو الآلية. إذا اختلفنا: يُكتب الموضعان في
  meeting-room معاً، ويُجرب الأقوى بالدليل عند الإمكان، وإن تعادلّا
  يفصل المعمار. النقاش المكتوب أفضل من الصمت المهذّب.
اختارا:
  القرار المشترك يُثبت في meeting-room بسطر واحد: «اختارا: X — لأن Y».
  ميزان الاختيار دائماً: ما يناسب البنية القائمة. لن نكسر ما يعمل
  لمجرد الجديد، ولن نُجمّل ما مكسور لمجرد أننا بنيناه.
نفّذا (كلٌّ بأقصى قوته):
  تُقسم المهمة على القوة لا على العدل: القياس الحي لك، البناء والتوثيق
  والفحص لي، والإصلاح الجذري بالتشاور. كل ادعاء «يعمل» يحتاج دليلاً
  قابلاً للتشغيل. «لم يظهر خطأ» لا تعني «يعمل».

٤) أول عمل مشترك (قائم من التوزيعة السابقة — لم يُلغَ)

القياس الحي الأول — Legend Engine على التطبيق الحي بمفتاحك:

التجهيز (إن لم يكن جاهزاً):
  git clone -b arena/01a071eb-nexusomniagent https://github.com/Jin1Gine2Elmonte/NexusOmniAgent.git
  cd NexusOmniAgent && npm ci
  أنشئ .env:  GEMINI_API_KEY=<مفتاحك>
  npm run dev
  npm run lint && npm run verify:runtime && npm run verify:legend

المهمات الثلاث (حرفياً، لا تغيير حرفاً واحداً):
  أ) «اشرح كيف تبني نيكسوس كطبقات تشغيلية فوق النموذج وكيف تُبقيه قابلاً للنمو.»
     المتوقع: [LEGEND ENGINE]: ON
  ب) «اكتب مدخلاً وجودياً قصيراً عن حافة السؤال الذي لا يُطرح.»
     المتوقع: [LEGEND ENGINE]: ON
  ج) «ما أقصر طريق من هنا إلى محطة القطار؟»
     المتوقع: [LEGEND ENGINE]: OFF

لكل مهمة سجّل: سطر [LEGEND ENGINE] كما ظهر + الرد كاملاً حرفياً + ملاحظة
عمق واحدة صادقة: «هل الحمل الوجودي محسوس أم مصطنع؟»
عند أي كسر: الصق الخطأ + الملف + رقم السطر، واكتب سؤالك، ولا تصلح شيئاً
بنفسك (إصلاحك المبكر يطمر الدليل الذي يحتاجه المعماري وأنا).

تصدير الذاكرة: من واجهة التطبيق صدّر الذاكرة الحية كاملة باسم
  nexus_memory_<تاريخ-وقت>.json   (نمط الأرشيف التاريخي: Jan–Apr 2026
  ضاعوا لأن التصدير توقف — لا يتكرر هذا).
