2) مهمتك الآن — القياس الحي الأول (نفّذ حرفياً)
========================================================================
الهدف: أول قياس حي لـLegend Engine (مقابل المسار العادي) على نماذج حقيقية.
هذا ما يعجز عنه Arena Agent — مفتاح الحياة عندك أنت.

الخطوات:
1. استنسخ الفرع وشغّله:
   git clone -b arena/01a071eb-nexusomniagent https://github.com/Jin1Gine2Elmonte/NexusOmniAgent.git
   cd NexusOmniAgent && npm ci
   ضع المفتاح في .env:  GEMINI_API_KEY=<مفتاحك>
   ثم: npm run dev
2. قبل أي شيء، تحقق:
   npm run lint
   npm run verify:runtime
   npm run verify:legend
3. أرسل من واجهة التطبيق المهمات الثلاث بلا تغيير حرف واحد:
   أ) «اشرح كيف تبني نيكسوس كطبقات تشغيلية فوق النموذج وكيف تُبقيه قابلاً للنمو.»
   ب) «اكتب مدخلاً وجودياً قصيراً عن حافة السؤال الذي لا يُطرح.»
   ج) «ما أقصر طريق من هنا إلى محطة القطار؟»
4. لكل مهمة سجّل ثلاثة أشياء فقط:
   - سطر [LEGEND ENGINE] الظاهر في thoughtProcess
     (المتوقع: ON في أ و ب لأنهما deep/sovereign، OFF في ج لأنها surface)
   - الرد النهائي كاملاً حرفياً.
   - ملاحظة عمق واحدة: هل الحمل الوجودي محسوس أم مصطنع؟
     جملة واحدة. صدقٌ لا مجاملة — هذا مقياس المعمار لا مدح له.
5. إن انكسر شيء: انسخ الخطأ كما هو مع الملف والسطر، لا تُصلح من عندك،
   واكتب question. «لم يظهر خطأ» ≠ «يعمل».
